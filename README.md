# Bike Landing Page

A responsive landing page for a bicycle shop. It presents the featured bikes, their benefits and a way to get in touch, and adapts to mobile, tablet and desktop screens.

## Live Preview

[![Live Demo](https://img.shields.io/badge/🚲_Live_Demo-Open_Site-5d5fff?style=for-the-badge)](https://droopy-bit.github.io/landing-page/)

Deployed on GitHub Pages: [https://droopy-bit.github.io/landing-page/](https://droopy-bit.github.io/landing-page/)

## Design Reference

The page is based on a Figma mockup: [View design](PASTE_FIGMA_LINK_HERE)

## Technologies Used

**Core**
- HTML5 — semantic markup
- CSS3 / SCSS — Flexbox, Grid, media queries
- BEM — class naming methodology

**Deployment**
- GitHub Pages

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/droopy-bit/landing-page.git
cd landing-page
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the project locally

```bash
npm start
```

The page will be available at the address shown in your terminal.

## Features

- **Responsive design** — adapts to mobile, tablet and desktop screens
- **Bike showcase** — featured bicycles with images and short descriptions
- **Semantic HTML** — clean and accessible markup
- **Smooth hover effects** on links and buttons
